# 太陽画像 回転角測定ツール

2枚の太陽画像を対応点で位置合わせし、透過重ね合わせで画像間の相対回転角を測定する独立GUIアプリケーションです。

## 主な機能

- TIFF（`.tif` / `.tiff`）および FITS（`.fits` / `.fit` / `.fts`）の2次元グレースケール画像を読み込み
- 画像A・画像Bで同じ特徴点を3点ずつクリック
- MIN2 v2.4.1による太陽円の中心・半径検出と画像間補正
- マウスドラッグによる中心・半径の手動調整
- 対応点から回転・一様倍率・平行移動を自動計算
- カーソル位置中心のZoom、ドラッグPan、表示リセット
- Aをシアン、Bを赤で表示する補色カラーマップによる重ね合わせ
- 重ね合わせ上にA/Bそれぞれの画像上方向を矢印で表示
- 重ね合わせ画面の左ドラッグによるB画像の回転と数値入力の同期
- 透過率スライダーによるリアルタイム重ね合わせ
- 追加回転による手動微調整
- 重ね合わせPNGと測定値JSONを保存
- 元画像は変更せず、解析用の画素値も上書きしません

## 動作環境

- Python 3.11以降
- Windows / macOS / Linux（デスクトップGUI環境）

## インストール（Windows）

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

仮想環境を有効化できない場合は、`.venv\Scripts\python.exe` を直接指定できます。macOS / Linuxでは `source .venv/bin/activate` を使用してください。

## 起動

リポジトリのルートディレクトリで次のコマンドを実行します。

```powershell
python run.py
```

パッケージとしてインストールした場合は、`solar-image-rotation-tool` コマンドでも起動できます。

## 基本操作

1. **画像 A を開く** から基準画像、**画像 B を開く** から比較画像を読み込みます。
2. 画像Aで同じ太陽特徴を3点クリックします。
3. **MIN2 v2.4.1で中心・半径を自動検出** を押すと、A/Bそれぞれの太陽円を検出し、Bの中心・半径をAに合わせます。
4. 検出がうまくいかない場合や微調整したい場合は **中心・半径をマウスで手動調整** を有効にします。円の中心をドラッグすると中心を移動し、右端のハンドルをドラッグすると半径を変更できます。円の外側からドラッグすると新しい円を作成します。
5. MIN2と対応点を併用する場合は **MIN2と併用（対応点から回転のみ補正）** を有効にします。A/Bで対応する特徴点を同じ順番で3点ずつクリックし、**対応点3組から回転のみ補正** を押してください。MIN2で求めた中心・半径・倍率・平行移動は維持され、対応点から求めた回転角だけが太陽円中心まわりに追加されます。
6. MIN2を使わない場合はチェックを外し、対応点3組を指定して **対応点3組から回転・倍率を補正** を押します。3点の最小二乗で回転・倍率・平行移動を求めます。
6. ホイールでカーソル位置を中心にZoom、中ボタンまたは右ボタンのドラッグでPanできます。ダブルクリック、または **全画像の表示をリセット** で表示範囲を戻せます。
7. 重ね合わせはAをシアン、Bを赤で表示します。両方が重なる部分は混色され、ずれた部分は補色の縁として見えます。透過率でBの寄与を調整できます。
8. 重ね合わせ画面ではA上方向をシアン矢印、変換後のB上方向を赤矢印で示します。画像上の左ドラッグでBを回転でき、回転角は数値欄にも反映されます。
9. **重ね合わせ画像・測定値を保存** で補色合成PNGとJSONを保存します。

同じ画像で4点目をクリックすると、その画像の3点選択が新しく始まります。**対応点をクリア** は選択マーカーを消し、**位置合わせを初期化** は変換を解除して中央配置へ戻します。

## 回転角の定義

画像座標は右向きが +X、下向きが +Y です。画面上の時計回りを正とします。

- `total_correction_angle_deg`: 画像Bを画像Aに重ねるためにBへ適用した総補正角
- `comparison_relative_rotation_deg`: Aを基準としたBの相対回転角（総補正角の符号を反転した値）

例えばBがAに対して画面上で時計回りに12°回転している場合、BをAへ合わせる補正角は-12°、Bの相対回転角は+12°です。

## 保存ファイル

指定したPNG保存先と同じ場所に、同名のJSONを保存します。

- PNG: Aを基準にBを変換して重ねた表示用画像
- JSON: 入力ファイル、クリック座標、回転角、倍率、変換行列、透過率、補色カラーマップ、上下方向ベクトルなど

## 測定上の注意

- 測定対象は2画像間の**相対画像回転**です。A/Bの矢印は各画像のピクセル座標における上方向（画像上端方向）を示し、太陽北方向を自動推定するものではありません。既知の北方向と結び付ける場合は、北方向が校正済みの基準画像が必要です。
- 対応点は同じ物理的特徴を正確に選び、3点をできるだけ広く分散して選択してください。点が狭い範囲に集中するとクリック誤差が角度に大きく影響します。
- 撮影時刻が異なる画像では、太陽自転・差動回転・黒点の変化による特徴点移動が測定に混入します。可能な限り撮影時刻が近い画像を使用してください。
- 3組の点から最小二乗の相似変換（回転・一様倍率・平行移動）を求めます。レンズ歪み、せん断、非一様倍率、鏡像反転は補正しません。鏡像反転の有無は別に確認してください。
- 画像ごとに表示用階調を独立して正規化します。保存PNGは可視化用であり、元の科学的画素値やTIFF/FITSメタデータは保持しません。

## Windowsの単純起動

Windowsではリポジトリ直下の `run.bat` をダブルクリックして起動できます。既存の `.venv` があればそのPythonを優先し、なければPATH上のPythonでルートの `run.py` を実行します。バッチファイルは起動のみを行い、仮想環境の作成や依存関係のインストール・更新は行いません。

## Zoom / Pan / 回転

- マウスホイール: カーソル位置を中心に拡大・縮小
- 中ボタンまたは右ボタンのドラッグ: 画像を移動
- 重ね合わせ画面の左ボタンをドラッグ: B画像を回転（時計回りが正）
- MIN2でA/Bの中心・半径補正済みの場合、回転軸はA側の太陽円中心。対応点のみの場合は画像中央
- キャンバスのダブルクリック: その画像を全体表示
- 「全画像の表示をリセット」: A/B/重ね合わせの表示をまとめてリセット

Zoom/Panは表示だけに適用されます。回転ドラッグは既存の追加回転値を更新するため、数値欄や保存JSONにも反映されます。対応点の保存座標は常に元画像のピクセル座標です。

## MIN2 v2.4.1 による太陽円の補正

[solar_disk_detection MIN2_v2.4.1](https://github.com/fuji-astronomy-club-coders/solar_disk_detection/tree/MIN2_v2.4.1/min2) を同梱し、画像A/Bそれぞれの太陽円中心と半径を検出します。検出後、画像Bの中心と半径を画像Aへ合わせる一様倍率・平行移動を適用します。

この補正は中心・半径のみを合わせ、回転角は推定しません。回転も合わせる場合は「MIN2と併用（対応点から回転のみ補正）」を有効にして対応点3組を指定してください。このモードではMIN2の倍率・平行移動を維持し、対応点から計算した回転だけを太陽円中心まわりに適用します。MIN2を使わずに対応点から位置合わせする場合は、3組の点から回転・倍率・平行移動を最小二乗で求めます。

MIN2の検出結果は画像上に円として表示します。検出が不十分な場合や微調整したい場合は「中心・半径をマウスで手動調整」を有効にし、円の中心マーカーまたは半径ハンドルをドラッグしてください。円がない画像では、中心位置から円周方向へドラッグして手動設定できます。A/B双方の円が設定されると補正が更新されます。

MIN2は既定で \`n=10\`、\`light_threshold=50\`、\`limb_wigth=24\`、\`iter_cycles=2\` を使用します。バンドルしたソースの出典とライセンスは [Third-party notices](docs/third_party_notices.md) を参照してください。
