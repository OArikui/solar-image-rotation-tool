# 測定仕様と注意事項

## 位置合わせの計算

各画像で指定した3組の対応点から、最小二乗の相似変換を求めます。対応点群の重心を基準に回転と一様倍率を推定し、重心位置が一致するよう平行移動を加えます。これにより、画像Bから画像Aへの2×3変換行列を得ます。

この変換は回転・一様倍率・平行移動のみです。せん断、非一様倍率、レンズ歪み、鏡像反転は扱いません。

## 北方向の推定に利用する場合

このツールが得るのは2画像間の相対角度です。相対角度だけから各画像の絶対的な太陽北方向を一意に決めることはできません。北方向が既知の基準画像を用意し、その基準方向に相対角度を適用して比較画像の方向を求めてください。鏡像反転の有無は別途確認してください。

## JSONの主な項目

| 項目 | 内容 |
|---|---|
| `reference_image` | 基準画像Aのパス |
| `comparison_image` | 比較画像Bのパス |
| `reference_points_px` | 画像Aで選択した3点のピクセル座標 |
| `comparison_points_px` | 画像Bで選択した3点のピクセル座標 |
| `automatic_correction_angle_deg` | 対応点から計算した自動補正角 |
| `manual_additional_angle_deg` | GUIで追加した微調整角 |
| `total_correction_angle_deg` | Bに適用した総補正角 |
| `comparison_relative_rotation_deg` | Aを基準とするBの相対回転角 |
| `comparison_to_reference_scale` | BからAへの一様倍率 |
| `comparison_to_reference_matrix` | BからAへの2×3変換行列 |
| `overlay_opacity_percent` | 保存時のB画像の透過率 |
| `overlay_colormap` | A/Bの補色表示設定（A: cyan、B: red） |
| `overlay_axes_origin_px` | 上方向矢印を表示する基準点 |
| `reference_image_up_vector_px` | A画像の上方向ベクトル |
| `comparison_image_up_vector_in_reference` | 変換後のA座標系におけるB画像の上方向ベクトル |

座標は各画像の左上画素を基準とする0始まりのピクセル座標です。Xは右向き、Yは下向きです。


## MIN2 v2.4.1 による中心・半径補正

アプリには [solar_disk_detection の MIN2_v2.4.1](https://github.com/fuji-astronomy-club-coders/solar_disk_detection/tree/MIN2_v2.4.1/min2) の \`MIN2_ignore_sunspots\` を同梱しています。A/Bそれぞれの画像から太陽円の中心 \`(cx, cy)\` と半径 \`r\` を検出します。

検出値を用いて、画像Bから画像Aへの一様倍率と平行移動を次のように求めます。

\`scale = r_A / r_B\`

\`translation = center_A - scale * center_B\`

この処理は**中心と半径を合わせる補正であり、回転角は推定しません**。回転角も合わせる場合は、MIN2併用の回転のみ補正モード、または追加回転の手動調整を使用してください。

MIN2検出が失敗した場合や検出円を微調整したい場合は、手動調整モードを有効にします。画像上の円中心をドラッグして中心を動かし、右端のハンドルをドラッグして半径を変更できます。既存の円がない場合は、画像上で中心から円周方向へドラッグして円を作成できます。A/B双方の円が設定されると、その値から中心・半径補正を再計算します。

MIN2の既定値は \`n=10\`、\`light_threshold=50\`、\`limb_wigth=24\`、\`iter_cycles=2\` です。大きな画像では処理に時間がかかる場合があります。

## 重ね合わせの補色表示と上方向ガイド

重ね合わせでは、基準画像Aをシアン（G+Bチャンネル）、比較画像Bを赤（Rチャンネル）として表示します。Bの透過率を変えることで寄与を調整します。同じ位置に同じ明るさの特徴がある場合は中間色になり、位置がずれた特徴は赤とシアンの縁として見分けやすくなります。表示用の色変換であり、元画像の画素値は変更しません。

重ね合わせ上には2本の矢印を表示します。シアンのA上矢印は画像Aの上端方向、赤のB上矢印は現在のB→A変換を適用した画像Bの上端方向です。両矢印は現在の回転操作の中心を基準に描画します。これらは画像座標の向きを示すガイドであり、太陽北方向そのものではありません。

重ね合わせ画面の左ボタンをドラッグすると、B画像を回転できます。画像座標では時計回りが正です。操作角度は「追加回転」の数値欄と測定値に反映されます。中/右ボタンのドラッグは従来どおりPan、ホイールはZoomです。保存PNGは補色合成画像、JSONには色設定と上下方向ベクトルを記録します。

## Zoom / Pan

- マウスホイール: カーソル位置を中心に拡大・縮小
- 中ボタンまたは右ボタンのドラッグ: 表示範囲を移動（Pan）
- キャンバスのダブルクリック: そのキャンバスを全体表示へ戻す
- 「全画像の表示をリセット」: A/B/重ね合わせの表示を同時に戻す

Zoom/Panは表示だけを変更します。クリック位置や保存される対応点座標は元画像のピクセル座標に変換されます。


## 3点対応とMIN2併用モード

対応点は画像A/Bそれぞれ3点ずつ指定します。MIN2を使用しない通常モードでは、3組の対応点に対して最小二乗の相似変換を当てはめ、回転・一様倍率・平行移動を算出します。

MIN2併用モードでは、まずMIN2で太陽円の中心・半径を合わせた変換を作成し、その変換行列の倍率と平行移動は変更しません。対応点3組からは回転角だけを推定し、画像A側の太陽円中心を回転の中心として追加します。したがってMIN2の中心・半径合わせを崩さずに、黒点などの対応点から画像回転だけを補正できます。

保存JSONの `landmark_fit_mode` は、通常の3点相似変換で `similarity`、MIN2併用の回転のみ補正で `rotation_only` になります。`automatic_rotation_pivot_px` には回転のみ補正で使用した画像A側の太陽円中心を記録します。
